# Image

A flexible image primitive that provides token-driven aspect-ratio and object-fit controls, optional rounded corners, and lazy-loading optimizations. It renders a semantic `<figure>` with an optional `<figcaption>`.

## Overview

The component's job is to display a single image with consistent styling across the design system. It does **not** handle responsive src-sets, picture elements, or complex cropping – those concerns belong to higher-level image utilities. The component focuses on token-driven sizing, object-fit, and optional visual tweaks like rounding.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| src | `string` | – | URL of the image (required by `MediaComponentProps`). |
| alt | `string` | – | Alternative text for accessibility (required). |
| caption | `string` | – | Optional caption rendered as `<figcaption>`. |
| ratio | `ImageRatio` (`'auto' | 'square' | 'video' | 'portrait' | 'wide'`) | `'auto'` | Aspect-ratio preset applied via CSS custom property. |
| fit | `ImageFit` (`'cover' | 'contain'`) | `'cover'` | CSS `object-fit` for the `<img>` element. |
| rounded | `ImageRounded` (`boolean` | `DisplaySize`) | `false` | Applies a border-radius class; `true` uses the default radius, a string selects a preset. |
| loading | `ImageLoading` (`'eager' | 'lazy'`) | `'lazy'` | Native lazy-loading strategy. |
| decoding | `ImageDecoding` (`'sync' | 'async' | 'auto'`) | `'async'` | Image decoding strategy. |
| class | `string` | – | Additional CSS class. |
| class:list | `Record<string, boolean>` | – | List of conditional classes. |
| style | `string | Record<string, string>` | – | Inline style. |
| animate | `string` | – | Animation class/name. |
| effects | `string[]` | – | Visual effects. |
| bg | `BackgroundTone` | – | Background tone class added by `mergeClasses`. |

*All props from `BaseComponentProps` and standard HTML attributes are supported.*

## Variants / Sizes

| Prop | Values | Effect |
|------|--------|--------|
| `ratio` | `'auto'`, `'square'`, `'video'`, `'portrait'`, `'wide'` | Sets `--local-ratio` custom property; `auto` leaves dimensions intrinsic. |
| `fit` | `'cover'`, `'contain'` | Sets `--local-fit` custom property controlling how the image fills its container. |
| `rounded` | `false`, `true`, or size preset (e.g., `'sm'`) | Adds a BEM modifier class via `resolveRoundedClass`. |

## Usage

### Basic

```astro
---
import Image from '@/design/media/image/Image.astro';
---
<figure>
  <Image src="/images/logo.png" alt="Company logo" />
</figure>
```

### Common Patterns

**Responsive ratio with cover fit**

```astro
---
import Image from '@/design/media/image/Image.astro';
---
<figure>
  <Image
    src="/images/hero.jpg"
    alt="Hero banner"
    ratio="wide"
    fit="cover"
    rounded="sm"
    loading="eager"
  />
</figure>
```

**Rounded thumbnail with lazy loading**

```astro
---
import Image from '@/design/media/image/Image.astro';
---
<figure>
  <Image
    src="/images/avatar.jpg"
    alt="User avatar"
    ratio="square"
    rounded
    loading="lazy"
    decoding="async"
  />
</figure>
```

**Image with caption**

```astro
---
import Image from '@/design/media/image/Image.astro';
---
<figure>
  <Image src="/images/diagram.svg" alt="Architecture diagram" />
  <figcaption>System architecture overview</figcaption>
</figure>
```

## Logic

The component does **not** contain an inline `<script>` block; all behavior is driven by native HTML and CSS. No external controller or Region component is used.

## Accessibility

* The required `alt` prop provides descriptive text for screen readers.
* The component renders a `<figure>` with an optional `<figcaption>` for semantic grouping.
* No custom ARIA roles are needed; accessibility relies on native image semantics.

## CSS Architecture

* Root BEM class: `image`.
* Modifier class for rounded corners generated by `resolveRoundedClass` (e.g., `image--rounded`).
* Token-driven custom properties:
  * `--local-ratio` from `IMAGE_VAR_MAP.ratio`.
  * `--local-fit` from `IMAGE_VAR_MAP.fit`.
* Global animation/effect/bg classes merged via `mergeClasses`.

## Related Components

* `Video` — analogous media component with similar token-driven sizing.
* `Audio` — sibling media primitive.
* `Spinner` — useful as a loading placeholder for images that load lazily.
