# Audio

A flexible audio primitive that can render native browser controls or a minimal custom overlay player. It provides a simple, accessible way to embed audio tracks while giving developers control over UI complexity.

## Overview

The component's job is to play an audio source and optionally present a minimal UI with play/pause, scrubber, and timestamp. It does **not** handle playlists, advanced visualizations, or custom decoding – those responsibilities belong to higher‑level media controllers. The component is deliberately lightweight, exposing only the props needed to configure source, format, and basic playback behavior.

## Props

| Prop      | Type                              | Default   | Description |
|-----------|-----------------------------------|-----------|-------------|
| src       | `string`                          | –         | URL of the audio file (required by `MediaComponentProps`). |
| caption   | `string`                          | –         | Optional caption rendered as `<figcaption>`. |
| title     | `string`                          | –         | Optional title displayed above the player. |
| label     | `string`                          | –         | Optional secondary label displayed below the title. |
| variant   | `'native' \| 'minimal' \| 'none'`| `'native'`| Controls UI: `native` shows full browser controls, `minimal` shows a custom overlay, `none` renders only the `<audio>` element without UI. |
| type      | `AudioMimeType` (see types file)  | –         | MIME type hint for the `<source>` element. |
| loop      | `boolean`                         | `false`   | Whether the audio should loop. |
| autoplay  | `boolean`                         | `false`   | Whether playback starts automatically. |
| muted     | `boolean`                         | `false`   | Whether the audio starts muted. |
| class     | `string`                          | –         | Global class prop merged via `mergeClasses`. |
| class:list| `Record<string, boolean>`         | –         | Object‑list class prop merged via `mergeClasses`. |
| style     | `string \| Record<string,string>` | –         | Inline styles merged via `mergeStyles`. |
| animate   | `string`                          | –         | Animation string processed by `mergeClasses`. |
| effects   | `string[]`                        | –         | Visual effects processed by `mergeClasses`. |
| bg        | `BackgroundTone`                  | –         | Background tone class added by `mergeClasses`. |

*All props from `MediaComponentProps` (`src`, `caption`) and `BaseComponentProps` (global props) are included.*

## Variants / Sizes

| Variant | Visual effect |
|---------|---------------|
| `native` | Full native browser UI (play, seek, volume, download). |
| `minimal`| Single‑line custom overlay with play/pause button, scrubber, and timestamp. |
| `none`   | No UI – only the `<audio>` element; useful for background audio. |

## Usage

### Basic

```astro
---
import Audio from '@/design/media/audio/Audio.astro';
---
<figure>
  <Audio src="/media/song.mp3" />
</figure>
```

### Common Patterns

**Native controls with caption**

```astro
---
import Audio from '@/design/media/audio/Audio.astro';
---
<figure>
  <Audio src="/media/podcast.mp3" variant="native" caption="Episode 12 – Design Systems" />
</figure>
```

**Minimal overlay with autoplay and loop**

```astro
---
import Audio from '@/design/media/audio/Audio.astro';
---
<figure>
  <Audio
    src="/media/ambient.wav"
    variant="minimal"
    autoplay
    loop
    title="Ambient Loop"
    label="Background ambience"
  />
</figure>
```

**Muted background audio (no UI)**

```astro
---
import Audio from '@/design/media/audio/Audio.astro';
---
<figure>
  <Audio src="/media/background.mp3" variant="none" muted />
</figure>
```

## Logic

The component contains an inline `<script>` that runs once on page load. It:

* Finds every element with `data-audio-player`.
* Reads data attributes (`src`, `loop`, `autoplay`, `muted`).
* Instantiates a native `Audio` object and wires up:
  * Play/pause button toggling.
  * Scrubber click handling for seeking.
  * Time‑update handling to update the progress bar and timestamp.
  * Autoplay handling when the `autoplay` attribute is true.

All behavior lives inside the component; there is no external controller file.

## Accessibility

* The native variant relies on the browser's built‑in accessibility for `<audio>`.
* The minimal overlay provides an accessible button with `aria-label` that toggles between "Play" and "Pause".
* Captions are rendered inside `<figcaption>` for screen‑reader context.
* No custom ARIA roles are required beyond the native element.

## CSS Architecture

* BEM root class: `audio`.
* Modifier class generated by `resolveVariantClass` (e.g., `audio--minimal`).
* No component‑specific CSS custom properties; layout is handled by the wrapper and token‑driven classes from the design system.
* Global animation, effects, and background classes are merged via `mergeClasses`.
