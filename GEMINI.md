# Project Rules

Before making significant changes:

1. Read:
   - .agents/memory.md
   - .agents/decisions.md

When a user preference is discovered:
   - Update .agents/memory.md

When an architectural decision is made:
   - Update .agents/decisions.md

When completing substantial work:
   - Append an entry to .agents/worklog.md

Never claim to remember something unless it has been written to memory.md.
